# MediQueue

## Project Overview

MediQueue is a responsive medical appointment and healthcare management web application. It is designed to help users explore healthcare services and manage medical appointment-related activities through a clean and modern frontend interface.

## Live Project Link

[Visit Live Website](https://mediqueue-sigma.vercel.app/)

## Repository Link

[GitHub Repository](https://github.com/WiZzard14/mediqueue)

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Firebase
- Vercel
- Responsive Web Design

## Core Features

- Responsive healthcare website interface
- Medical appointment related user interface
- Clean and modern design
- User-friendly navigation
- Dynamic content display
- Mobile, tablet, and desktop friendly layout

## Dependencies Used

- react
- react-router-dom
- tailwindcss
- firebase
- daisyui
- react-icons
- sweetalert2

## How to Run the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/WiZzard14/mediqueue.git
```

2. Go to the project folder:

```bash
cd mediqueue
```

3. Install dependencies:

```bash
npm install
```

4. Run the project:

```bash
npm run dev
```
